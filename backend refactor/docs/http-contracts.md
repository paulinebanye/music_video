# HTTP Contracts

## GET /music
- Auth: none (public)
- Query Params: none
- Request Body: none
- Responses:
  - 200: HTML document rendered from `index.html`
    ```html
    <!DOCTYPE html>
    <html>
      <head>...</head>
      <body><div id="root"></div></body>
    </html>
    ```

## ANY /music/admin/*
- Auth: Django admin session (staff credentials, CSRF-protected forms)
- Query Params: standard Django admin filters
- Request Body: varies by admin action (HTML form submissions)
- Responses:
  - 200: Django admin HTML pages
  - 302: Redirects to login when unauthenticated

## GET /api/v1/sidebar
- Auth: none (AllowAny)
- Query Params:
  - `org` (string, optional but required for enriched payload)
  - `user` (string, optional but required for enriched payload)
- Request Body: none
- Responses:
  - 200: Sidebar payload with plugin metadata when `org` and `user` match an organisation member
    ```json
    {
      "event": "sidebar_update",
      "plugin_id": "music.zuri.chat",
      "data": {
        "name": "Music Plugin",
        "organisation_id": "619ba4671a5f54782939d384",
        "room_id": "61a4c1cd4f88198ec49dd636",
        "user_id": "user-123",
        "public_rooms": [
          {
            "room_name": "Music Room",
            "room_url": "/music/61a4c1cd4f88198ec49dd636",
            "room_image": "https://svgshare.com/i/aXm.svg"
          }
        ]
      }
    }
    ```
  - 204: When either `org` or `user` is missing
  - 401: When user is not part of the organisation
  - 424: When the org members API fails

## GET /music/api/v1/ping
- Auth: none (AllowAny)
- Query Params: none
- Request Body: none
- Responses:
  - 200: Confirmation that the external music site is reachable
    ```json
    {
      "server": [
        {
          "status": "Success",
          "Report": ["The music.zuri.chat server is working"]
        }
      ]
    }
    ```
  - 424: Failure to contact external service
    ```json
    {
      "server": [
        {
          "status": "Failed",
          "Report": ["The music.zuri.chat server is not working"]
        }
      ]
    }
    ```

## POST /music/api/v1/install
- Auth: requires `Authorization` header (bearer or session token forwarded to Zuri API)
- Query Params: none
- Request Body:
  ```json
  {
    "user_id": "user-123",
    "organisation_id": "619ba4671a5f54782939d384"
  }
  ```
- Responses:
  - 201: Successful install
    ```json
    {
      "message": "Plugin successfully installed!",
      "success": true,
      "data": {"redirect_url": "/music"}
    }
    ```
  - 400: Plugin already installed
    ```json
    {
      "message": "Plugin has already been installed!",
      "success": false,
      "data": null
    }
    ```
  - 424: Upstream error from Zuri API
    ```json
    {
      "message": "There is an Error with this installation! Please contact Admin",
      "success": false,
      "data": null
    }
    ```

## GET /music/api/v1/org/<org_id>/room/<_id>/songs
- Auth: none (AllowAny)
- Query Params: none
- Request Body: none
- Responses:
  - 200: Songs retrieved from Zuri data store
    ```json
    {
      "status": 200,
      "data": [
        {
          "_id": "song-1",
          "title": "Song Title",
          "duration": "00:03:45",
          "albumCover": "https://...",
          "url": "https://youtube.com/watch?v=...",
          "userId": "user-123",
          "addedBy": "Alice",
          "likedBy": [],
          "time": 1638383838
        }
      ]
    }
    ```
  - 204: No songs present
    ```json
    {"no songs in collection": null}
    ```
  - 400: Serializer validation errors (e.g. empty payload)
    ```json
    {"url": ["This field is required."]}
    ```

## POST /music/api/v1/org/<org_id>/room/<_id>/songs

    ```json
      "albumCover": "https://img.youtube.com/...",
    ```

    ```json
    "Song updated but Centrifugo is not available"
    ```
  - 400: Serializer validation errors
    ```json
    {"url": ["This field is required."]}
    ```

## POST /music/api/v1/org/<org_id>/room/<_id>/songs/like
- Auth: none (AllowAny)
- Query Params: none
- Request Body:
  ```json
  {
    "song_id": "song-1",
    "memberId": "user-987"
  }
  ```
- Responses:
  - 201: Song liked successfully
    ```json
    {
      "event": "like_song",
      "message": "success",
      "data": {
        "song_id": "song-1",
        "new_ids": "user-987",
        "action": "song liked successfully"
      }
    }
    ```
  - 424: Centrifugo publish failure or update failure
    ```json
    "Song liked but Centrifugo is not available"
    ```
  - 302: Song already liked by user
    ```json
    "Song already liked"
    ```
  - 400: Serializer validation errors
    ```json
    {"song_id": ["This field is required."]}
    ```

    ```json
        "query": "jazz",
        "filter": [],
        "plugin": "Music"
      },
      "results": {
        "entity": "others",
        "data": [
          {
            "_id": "song-1",
            "title": "Jazz Vibes",
            "images_url": ["https://..."],
            "created_at": 1638383838,
            "created_by": "Alice",
    ```
